# URMIRA - Homemade & Natural Foods
> ঘরে তৈরি ভালোবাসার খাবার (Pure • Natural • Homemade)

URMIRA (উর্মিরা) is a luxury e-commerce web application for a Bangladeshi homemade and natural food brand specializing in Pure Desi Cow Ghee (bilona method), premium Ajwa dates, almonds & dry fruits, handmade energy balls, sugar-free date bars, and royal gift hampers.

## ✨ Features
- **Two-Level Responsive Header**: Top announcement/trust bar and sticky main navigation with live search, wishlist, and cart drawer.
- **Hero Showcase**: Prominent lifestyle food composition with direct CTA and WhatsApp ordering.
- **5-Point Trust Bar**: 100% Homemade, Natural Ingredients, Freshly Prepared, Cash on Delivery, Secure Packaging.
- **6 Rectangular Category Cards**: Dates, Almonds & Dry Fruits, Pure Ghee, Energy Balls, Homemade Snacks, Gift Packs.
- **Best Sellers Catalog**: 6 products with price calculation, star ratings, Add to Cart & WhatsApp order buttons.
- **Special Offer Banner**: 30% Off First Order luxury promotional card.
- **Interactive Product Spotlight**: Pure Desi Cow Ghee size switcher (`250ml`, `500ml`, `1kg`) with live dynamic pricing and prefilled WhatsApp link generator.
- **Brand Story & Why URMIRA**: 4 core benefit cards (`বিশুদ্ধ উপকরণ`, `যত্নসহকারে প্রস্তুত`, `নিরাপদ প্যাকেজিং`, `দ্রুত সাপোর্ট`).
- **Interactive Cart & Checkout**: Slide-out cart drawer, quantity modifier, subtotal calculator, and quick COD checkout modal.
- **Mobile Optimized**: Full responsive layout with mobile drawer and sticky bottom navigation (Home, Categories, Cart, WhatsApp, Account).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ashikurrahmanshaon/urmira.git

# Navigate to project directory
cd urmira

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be running locally at `http://localhost:5173/`.
